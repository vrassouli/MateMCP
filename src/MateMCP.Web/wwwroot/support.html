MateMCP Support

Find the right place to ask a question, report a bug or flag a security issue.

Product help and bug reports

For setup questions, troubleshooting, feature requests and reproducible bugs, use the MateMCP GitHub issue tracker. Include the component, operating system, MateMCP version, steps to reproduce and relevant sanitized logs.

Security reports

Please do not publish credentials, access tokens, private keys, personal data or exploitable vulnerability details in a public issue. For sensitive vulnerability reports, use GitHub's private security advisory reporting flow when available.

Account and privacy requests

For account access or privacy requests, start with the project issue tracker and ask for a private follow-up before sharing account identifiers or other personal information. Do not include passwords, Agent credentials or secret values in a support request.

Before opening a report

  • Check the README and setup guidance.
  • Search existing issues for the same behavior.
  • Remove tokens, email addresses, file contents and other sensitive values from logs and screenshots.
  • For connection problems, include the MCP client name, Agent platform and whether OAuth completed successfully.

MateMCP is maintained as an open-source project. Public issue responses are visible to everyone; do not use public issues to transmit confidential information.
